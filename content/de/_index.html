Docker Traefik Cloudflare Paasbox Keycloak Prometheus Grafana FlowG

Plattform Services

Die Grundlage um jede Instanz

CMDB

Paasbox organisiert Infrastruktur, Docker Hosts und Instanzen als operative Quelle der Wahrheit.

Authentifizierung

Keycloak liefert Identity, SSO und gruppenbasierte Zugriffe fur Admin und Kunden Workflows.

Monitoring

Prometheus sammelt Metriken der Plattform, Container und Lifecycle Automatisierung.

Dashboard

Grafana macht Plattformmetriken als Dashboards fur Kapazitat, Zustand und Betrieb sichtbar.

Logging

FlowG zentralisiert Container und System Logs, damit Betreiber Aktivitat nachvollziehen konnen.

Routing

Traefik routet offentlichen Traffic zu jedem Service und wendet Edge Regeln automatisch an.

DNS und Edge

Cloudflare verwaltet DNS und Edge Schutz fur Domains, die von der Plattform erstellt werden.

Runtime

Docker fuhrt Container, Volumes und Lifecycle Operationen hinter jeder Bestellung aus.
