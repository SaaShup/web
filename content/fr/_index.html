Comment ça marche

Un client de plus. Zéro configuration.

4 étapes de votre image Docker à un SaaS avec de nombreux clients.

  1. Apportez votre app, gardez votre marque

    Partez de votre image Docker telle qu'elle est aujourd'hui. Ajoutez votre logo et votre domaine ; le HTTPS est automatique.

  2. Chaque client reçoit sa propre copie, automatiquement

    Un client s'inscrit et sa copie privée est prête en 2 minutes environ, sur sa propre adresse, avec son propre login. Aucune configuration de votre côté.

  3. Une seule mise à jour. Tout le monde l'a.

    Publiez une nouvelle version et chaque client est mis à jour. Un problème ? Annulez en un clic.

  4. Plus de clients, vos soirées restent libres

    Votre nombre de clients augmente ; votre temps de configuration, non.

Questions

Des réponses claires.

  • Dois-je tout configurer moi-même ?

    Non. Vérifiez ci-dessous si votre app convient, saisissez votre image Docker et inscrivez-vous. Les nouveaux clients sont ensuite ajoutés automatiquement. Besoin d'aide ? Contactez-nous et nous la configurerons avec vous.

  • Quelles apps fonctionnent sur SaaShup ?

    Les applications web qui tournent à partir d'une image Docker. Votre app convient si :

    • elle tourne à partir d'une image Docker ;
    • chaque client a besoin de sa propre copie, avec ses propres données ;
    • elle fonctionne sur n'importe quelle adresse web, par exemple votre propre domaine, sans modifier le code.

    Les apps avec plusieurs services (par exemple app + base de données) fonctionnent aussi : chaque service tourne séparément. Pas sûr ? Vérifiez ci-dessous si votre app convient.

  • Où sont hébergées mes données ?

    Dans des datacenters européens par défaut. D'autres régions sont possibles sur demande.

  • Puis-je partir ?

    Oui. Aucun verrouillage : votre app reste une image Docker standard, vous pouvez donc la faire tourner n'importe où. Les données de vos clients restent dans votre app : si vous devez les exporter ou les copier, c’est votre app qui le fait. SaaShup n’a pas d’outil d’export séparé.

  • Combien ça coûte ?

    Vous payez pour les clients qui utilisent votre app. Pas de clients, pas de facture. Consultez les offres sur notre page tarifs.
